Experience the Yamaha R15 V3

The Yamaha R15 V3 is a lightweight sport motorcycle designed for riders who want a combination of performance, style, and everyday usability.

About the Yamaha R15 V3

Sportbike Design

The R15 V3 features an aggressive aerodynamic design inspired by Yamaha's R-Series family. Its sharp bodywork and sporty riding position give it a distinctive racing appearance.

Engine Performance

The motorcycle uses a liquid-cooled single-cylinder engine designed to provide responsive performance while remaining suitable for everyday riding.
